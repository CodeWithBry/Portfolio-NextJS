# 👋 Bryan Pajarillaga — Personal Portfolio

> A personal portfolio website I built to showcase my projects, skills, and a little bit about myself. Made with **Next.js**, **TypeScript**, and **Tailwind CSS**.

🔗 **Live Site:** [portfolio-next-js-theta-tawny.vercel.app](https://portfolio-next-js-theta-tawny.vercel.app/)

---

## 📖 About This Project

This is my personal portfolio website that I made from scratch as a Senior High School student taking ICT at Dr. Yanga's College, Inc. in Bulacan, Philippines. I built this to practice my web development skills and to have a place where I can show what I've been working on.

The site has smooth scroll animations, a light/dark mode toggle, a responsive navbar with a hamburger menu for mobile, and sections for my skills, projects, and contact info.

---

## ✨ Features

- **Light / Dark Mode** — Toggle between themes, the whole site switches colors smoothly
- **Scroll Animations** — Sections and cards fade/slide in as you scroll down the page
- **Responsive Design** — Works on mobile, tablet, and desktop
- **Sticky Navbar** — Always visible at the top, highlights the active section
- **Scroll to Top Button** — A little button that appears so you can jump back to the top
- **Projects Showcase** — Cards with a browser mockup style, GitHub and Demo links
- **Skills Section** — Displays my tech stack with tags like frontend, backend, etc.
- **Contact Section** — A way for people to reach out to me
- **Static Export** — Built as a static site so it can be deployed anywhere (Vercel, GitHub Pages)

## 🚀 Getting Started

If you want to run this locally, here's how:

### Prerequisites

Make sure you have **Node.js** installed. You can check with:

```bash
node -v
```

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/CodeWithBry/Portfolio-NextJS.git
cd Portfolio-NextJS
```

**2. Install dependencies**

```bash
npm install
```

**3. Run the development server**

```bash
npm run dev
```

Then open your browser and go to [http://localhost:3000](http://localhost:3000)

## 🎨 Theme / Color System

I set up custom colors in `tailwind.config.ts` so I could easily switch between light and dark mode across the whole site:

```
bg-bg            → #0D0D0F  (dark background)
bg-bg-surface    → #18181C  (card/surface dark)
bg-bg-border     → #2A2A30  (border dark)
accent           → #6D40FF  (purple accent color)
accent-hover     → #8A63FF  (lighter purple on hover)
content-primary  → #F2F0FF  (light text)
content-secondary→ #9B97B2  (muted text)
```

## 🌐 Deployment

This portfolio is deployed on **Vercel** and also supports GitHub Pages via `gh-pages`.

**Deploy to GitHub Pages:**

```bash
npm run deploy
```

This runs `next build` first (which exports to `/out`), then pushes the output to the `gh-pages` branch.
